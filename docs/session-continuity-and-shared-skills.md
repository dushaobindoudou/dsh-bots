# 共享技能与会话连续性

## 改动归属

| 包与源码目录 | 负责的实现 |
| --- | --- |
| `multibot-sdk`：`~/workspaces/sdk-bots` | 引擎执行起点、共享技能库与完整技能安装、Bot 自行安装工具、技能提示注入、目标进展验证和持续调度 |
| `dsh-bots`：本仓库 | DSH 技能目录桥接与共享确认、安装及调用界面、引擎状态转发、计时展示、头像动画、原生侧栏交互、文件预览 |
| `finance-skill`：本仓库 `skills/finance-skill` | 金融数据脚本、依赖和取数说明；通过共享技能机制供所有 Bot 使用 |

通用 Bot 执行能力在 `multibot-sdk` 中实现，DSH 接入和展示在 `dsh-bots` 中实现。插件直接调用引擎接口，例行任务和技能安装不依赖浏览器运行。

工作台不再提供单独的「目标」模块（2026-10-09 下线）：目标就是用户在对话里表达的意图，Bot 用引擎的例行任务工具自行推进；群聊「任务规划」条只读展示各成员的例行任务。

## 使用与行为

技能设置页支持安装完整的本机技能目录、GitHub 仓库根目录及 `tree/<分支>/<技能目录>`、`blob/<分支>/<目录>/SKILL.md` 链接。必须含有效的 SKILL.md（name、description 和正文），scripts、references、assets 随目录一起进入引擎的全局 workflows 库。两个 Bot 和群聊使用同一份文件；安装不执行技能脚本。Bot 自己可以调用：

```json
{"target":"workflow","action":"install","source":"/absolute/path/to/skill"}
```

DSH 技能桥扫描 `~/.dsh/skills`、`~/.agents/skills`、`~/.codex/skills` 与插件内置技能。支持目录软链，名称重复时按上述优先级选择。每 15 秒发现新技能，设置页和聊天加载时也立即同步。同步保留其他插件的记录和认证信息。

共享需要确认：共享的技能会作为指令交给每个 Bot 和群聊，所以新发现的技能处于「待确认」，不会进入引擎目录，直到用户在设置页勾选并保存；未勾选即视为不共享。插件内置技能默认共享。决定记录在 `<数据目录>/dsh-bots-skill-bridge.json`（v2：`shared` 记录共享时 SKILL.md 的 sha256，`declined` 记录不共享的 ID）；共享后文件内容变化会在设置页标为「共享后内容已变更」，重新保存即确认新内容。旧版 v1 的排除列表原样迁移，已共享的技能保持共享；v2 文件同时保留 v1 的 `excluded` 字段，精确列出所有未共享的技能，保证仍在运行的旧宿主（或降级后）读到新文件时共享集合不变。中文目录名的技能使用基于真实路径的稳定 ID（`dsh-skill-<8位哈希>`），不随扫描顺序变化。

Bot 通过 `update_state` 自行安装进全局库的技能仍由引擎直接生效，插件无法拦截；如需同样的确认流程，需要在 `multibot-sdk` 侧为 Bot 安装增加用户确认。聊天里输入 `@` 可查找技能，选择后插入引擎识别的技能 ID，避免同名 Bot 混淆。

所有 Bot 和群聊的系统提示发布技能名称、用途和真实文件路径。Bot 先读完整 SKILL.md，再从该目录定位脚本和引用文档。安装的新技能在下一轮模型请求中可用。

带 `disable-model-invocation: true` 的技能同样进入共享目录和 `@` 菜单，但不进入模型自动发现目录；只有用户明确调用时才执行。

会话执行时间由引擎的执行窗口起点 `runStartedAt` 计算。切换聊天、返回原生工作区和刷新页面均不会重置；下一次执行有新的起点。旧引擎只能从界面首次观测执行状态时估算，刷新无法恢复其真实起点，因此完整功能需同时更新关联的 `multibot-sdk`。

头像按思考、执行工具、等待用户、重试、未读及休息切换姿态；身份只控制配色。动画过渡和视线采样共用时间轴，尊重系统减少动态效果设置。会话在原生 main 面板中显示，使用侧栏切换；顶部无关闭按钮，Escape 仅关闭菜单和对话框。

以下为引擎侧的目标台账协议（`multibot-sdk` 的 goal 类例行任务使用；工作台已不再创建这类任务）。目标执行沿用引擎持久化调度，关闭浏览器后继续。除完成验收项外，可以记录阶段成果：

```json
{
  "completedSteps": [{
    "id": "collect-source",
    "summary": "取得并核对第一份资料",
    "evidence": [{"path": "/absolute/path/source.json", "sha256": "64位小写十六进制SHA-256"}]
  }]
}
```

引擎核对文件内容与哈希；新证据可以重置停滞计数，修改时间戳或描述不会。重复、缺失及哈希不匹配的证据不算进展。真正缺少用户输入时暂停并给出原因；验收项全部成立后进入待验收，由用户确认或退回继续改进。

内置 `finance-skill` 的行情入口无需第三方 Python 包，财务等接口使用 requirements.txt。脚本成功必须同时满足退出码 0 与 JSON `ok=true`；空结果、错误代码、无请求周期或无请求复权数据均报告失败。港美股标注延时并保留数据时间，抓取时间含北京时间偏移。接口名称和财务字段参考 [AKShare 官方文档](https://github.com/akfamily/akshare/blob/main/docs/data/stock/stock.md)，具体行情取自脚本返回的腾讯源，不混用不同市场的成交额单位与涨跌停字段。

关联引擎源码：`~/workspaces/sdk-bots`。需构建并更新该引擎及 dsh-bots，再重启相应进程，运行中的旧进程不会自动加载源码变更。
